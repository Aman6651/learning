## About

This repository demonstrates how Git commit dates affect GitHub's contribution graph. It uses [Shpota's GitHub Activity Generator](https://github.com/Shpota/github-activity-generator).

> **Transparency note:** The timestamps in the activity log are synthetic demo data. They do not represent daily software development, completed learning work, or professional contributions.

## Explore

- [Generated activity log](generated-activity-log.txt) — timestamp entries used for the demonstration.
- [Generator source](https://github.com/Shpota/github-activity-generator/blob/main/contribute.py) — the script that creates the dated commits.

## Purpose

A small, transparent demo of how Git commit dates appear on a GitHub contribution graph.
